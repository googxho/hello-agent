# prompts/ 里的两个提示词文件

| 文件 | 是什么 |
|---|---|
| `system.md` | **默认提示词**（v1 那四条工作规则）。平时改的就是它 |
| `system-degraded.md` | ⚠️ **故意写坏的提示词**，只用于实验：拿它跑同一份卷子，看分数掉下去 |

## 用法

```bash
# 用默认提示词跑评估
python main.py --eval

# 用「坏提示词」跑同一份卷子，并和上一次对比
python main.py --eval --prompt prompts/system-degraded.md --baseline latest
```

## 为什么把提示词放成文件？

这一版的正题是「改了 prompt，不知道是变好还是变坏」——
所以「改 prompt」必须变成一件**随手可做、可对比**的事：

- 改文件 → 跑评估 → 看分数，而不是打开 `.py` 改字符串再重启
- 每次评估都会在开头打印提示词的 **sha 指纹**（8 位）：
  分数对比时会并排显示「`a1b2c3d4` → `77b0e2f1`（变了）」，
  你立刻知道这次分数变化是不是提示词带来的

`system-degraded.md` 里没有任何「这是实验用品」的注释 —— 因为文件内容会
**原样发给模型**，写注释等于让模型看见剧本。它的来龙去脉写在这份 README 里。
